### EPA 核心概念 | EPA Core Concepts

**EPA (Entrustable Professional Activities)** = 可信賴專業活動

將傳統「以時間為本」的訓練模式轉變為「以能力為本」的個別化學習路徑。

**Key Features**:
- 可觀察 (Observable)
- 可評估 (Assessable)
- 可信賴 (Entrustable)
- 整合性 (Integrative)

## 🛠️ 使用指引 | Usage Guide

### LaTeX 編譯 | LaTeX Compilation

**必要套件**:
- `xeCJK` - 中文支援
- `fontspec` - 字型設定
- `tikz` - 圖形繪製
- `tcolorbox` - 文字框
- `beamer` - 簡報製作

**字型需求**:
- Noto Serif CJK TC
- Noto Sans CJK TC

**編譯指令**:
```bash
xelatex filename.tex
```

### HTML 客製化修改 | Customizing HTML

所有HTML檔案可直接用文字編輯器修改：
- 修改配色：搜尋 `background: linear-gradient`
- 增減項目：複製貼上評估項目區塊
- 調整文字：直接修改中文內容
- 新增科別：在下拉選單中添加選項
