共用欄位結構

每個次專科表單都包含以下結構：

基本資料區（Section: 基本資料）

欄位名稱 類型 說明 必填 驗證
{prefix}_eval_date text 評核日期 Y date_ymd
{prefix}_assessor_name text 評核教師姓名 Y —
{prefix}_assessor_email text 評核教師電子信箱 Y email, @CHARLIMIT=100
{prefix}_assessor_title dropdown 評核教師職稱 — 1=主治醫師, 2=總醫師, 3=其他

被評核學員區（Section: 被評核學員）

欄位名稱 類型 說明 必填 驗證
{prefix}_evaluated_id text 學號/員工編號 Y @CHARLIMIT=20
{prefix}_evaluated_name text 被評核學員姓名 Y @CHARLIMIT=50
{prefix}_evaluated_type dropdown 學員類別 Y 1=醫學生, 2=PGY, 3=住院醫師, 4=NP
{prefix}_trainee_type dropdown 受評者類型 Y 同上
{prefix}_trainee_name text 受評者姓名 Y —
{prefix}_dept text 評核科別 — @DEFAULT, @READONLY

EPA 評估項目區（Section: EPA評估項目）

欄位名稱 類型 說明
{prefix}_section_epa descriptive 評分標準說明（不收集資料）
epa_{prefix}_{1~N} dropdown 各 EPA 項目評分

EPA 評分選項（所有 EPA 統一）：

值 描述
0 未評估
1 Level 1 - 新手：僅能觀察他人執行，需督導引導
2 Level 2 - 進階初學者：可在直接監督下執行
3 Level 3 - 勝任：可獨立執行但需回報
4 Level 4 - 精通：可獨立執行，監督者隨時可得
5 Level 5 - 專家：可獨立執行並指導他人
提示

每個 EPA 選項都包含該科特定的行為指標描述（Field Note 欄位記錄核心能力）。

整體評語區（Section: 整體評語）

欄位名稱 類型 說明
{prefix}_section_comments descriptive 回饋說明文字
{prefix}_overall_comments notes 整體質性評語（建議語音輸入）
{prefix}_strengths notes 優點與具體表現
{prefix}_areas_improvement notes 需改進之處與學習建議
{prefix}_recommendation dropdown 是否建議進入下階段

建議選項：

值 描述
1 是 — 可進入下階段
2 尚可 — 需持續觀察
3 保留 — 需加強訓練
