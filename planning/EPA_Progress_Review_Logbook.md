# 貳、專案總覽（Project Overview）

## 專案目標

建立內科部專科護理師（NP）EPA（Entrustable Professional Activities）評核制度，由各次專科主治醫師（VS）對 NP 進行 EPA 信賴等級評分（Level 1-5），透過 REDCap 系統每週批次發送問卷，9 週內完成全部評核。

## 關鍵數字

| 項目 | 數量 |
|------|:----:|
| VS 主治醫師 | 45 位（8 個次專科） |
| NP 納入評核 | 35 位（排除 2 護理部 + 2 包小夜；新增陳宏鈞） |
| REDCap record 總數 | 41+（含跨科 NP 重複；陳宏鈞待調查後加入） |
| 跨科 NP | 6 位 + 陳宏鈞（全科跨輪） |
| 每週發送量 | 4-5 筆 |
| 執行期 | 9 週（4/7 ~ 6/8） |
| EPA 總數（網站內容） | 123 個 EPA，12 個次專科 |
| 全部完成預計 | 2026/08 |

## 技術架構

- **評核平台**: REDCap（Survey + Data Management）
- **EPA 內容網站**: Quarto + GitHub Pages
- **資料字典**: `EPA_DataDictionary_v3_2026-04-06.csv`
- **排程工具**: Excel + Markdown 計畫文件

# 伍、REDCap 操作 SOP

> 完整 8 步驟流程。適用情境：多位 VS × 多位 NP（多對多評核）

## 前置確認

- [x] REDCap 專案已啟用 **Use surveys in this project?**
- [x] Data Dictionary 已匯入（v3, 2026-04-06）
- [x] 各次專科 instrument 已在 Designer → Enable 開啟 Survey 功能
- [ ] Survey Settings 各 form 設為 **By Invitation Only**

## Step 1：取得評核配對名單

向助理索取 Excel 或 CSV，需包含以下欄位：

| 欄位 | 說明 | 範例 |
|------|------|------|
| `assessor_name` | 評核醫師姓名 | 王大明 |
| `assessor_email` | 評核醫師 email | wang@ntuh.gov.tw |
| `assessor_title` | 職稱代碼 | `1`=主治醫師、`2`=總醫師、`3`=其他 |
| `evaluated_name` | 被評核護理師姓名 | 李小芬 |
| `evaluated_id` | 護理師員工編號 | N001234 |
| `form_name` | 要填的次專科 form | `cv_epa`、`chest_epa` ... |

> 一位醫師評 N 位護理師 → 該醫師的 email 出現 N 次，對應不同護理師。

## Step 2：轉換成 REDCap Import CSV

每列一筆 record，欄位名以 `{prefix}_` 開頭（如 `cv_assessor_name`）。
`evaluated_type` 代碼：`1`=醫學生、`2`=PGY、`3`=住院醫師、`4`=專科護理師。
可使用 `generate_redcap_csv_v3.py` 自動產出。

## Step 3：匯入 Records 至 REDCap

1. 左側選單 → **Data Import Tool**
2. 上傳 CSV → **Insert new records** → 確認預覽 → **Import Data**
3. 至 **Record Status Dashboard** 確認 record 已建立

## Step 4：設定各 Form 為 Survey

1. **Designer** → 找到 instrument → 點 **Enable**
2. Survey Settings：Title / Access = `By Invitation Only` / Expiration
3. Save

## Step 5：設定 Participant List 並批次寄送

1. **Survey Distribution Tools → Participant List**
2. 選擇 instrument → **Add participants from existing records**
3. 選取全部 → **Compose Invitations** → 貼入信件範本
4. **Send Invitations**

## Step 6：設定自動提醒

- 第一次提醒：寄出後 3 天（未完成者）
- 第二次提醒：截止前 2 天

## Step 7：追蹤回覆

| 狀態 | 說明 |
|------|------|
| `Not yet sent` | 尚未寄出邀請 |
| `Invited` | 已寄出，尚未填寫 |
| `Reminder sent` | 已寄出提醒 |
| `Completed` | 已完成填寫 |

## Step 8：匯出資料分析

- **Data Exports, Reports, and Stats** → 選格式（Excel / CSV / SPSS / R / STATA）
